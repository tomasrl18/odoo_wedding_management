Wedding Management

This module helps wedding planners manage weddings in Odoo 15, bringing guests, seating, vendors, budgets, tasks, and wedding-day schedules together in one application.

Key Features

  • Manage weddings with couple contacts, dates, venues, and responsible users
  • Track guest invitations, attendance, companions, and menu preferences
  • Organize seating arrangements with table capacity and occupancy tracking
  • Manage vendor bookings, agreed amounts, advance payments, and payment deadlines
  • Track estimated and actual expenses by budget category
  • Assign preparation tasks and organize wedding-day timelines
  • Collaborate using chatter and activities on weddings, tasks, and vendor bookings
  • Print wedding summaries, guest and table lists, and budget reports
  • Control access with Wedding Coordinator and Wedding Manager roles
